SMART PACK · MULTIPLAST — V11.6 CONSEGNA CLIENTE

FUNZIONI AGGIUNTE
1. Configurazione azienda
   - accessibile ai ruoli ufficio autorizzati (Gestione Smart Pack, Responsabile Multiplast, Amministrazione)
   - dati aziendali modificabili: ragione sociale, P.IVA, CF, SDI, sedi, PEC, email, telefono, sito, referente, note
   - selezione Smart Pack / Multiplast in base ai permessi dell'account

2. Importazione / aggiornamento Excel
   - file .xlsx, .xls e .csv
   - anteprima prima dell'importazione
   - modalità "Unisci / aggiorna" oppure "Sostituisci sezioni"
   - importa: clienti, prodotti, macchine, stampi, IML, ordini, operatori e scadenze
   - backup automatico prima dell'importazione e ripristino ultimo import
   - storico delle importazioni
   - esportazione dei dati correnti in Excel per modificarli e reimportarli
   - modello Excel incluso: IndustrialOS_Modello_Import_Dati_Azienda.xlsx

3. Guida interattiva / modalità dimostrazione sicura
   - proposta al primo accesso per ogni ruolo
   - pulsante Guida disponibile nella topbar
   - accompagna l'utente modulo per modulo
   - usa i moduli realmente disponibili per il ruolo
   - NON crea dati fittizi e NON modifica dati reali
   - ripristinabile dalla Configurazione azienda

4. Accesso NOMYRA / cliente
   - la Configurazione azienda è disponibile agli account amministrativi autorizzati
   - gli USER + PIN dei dipendenti restano gestiti separatamente per sicurezza

NOTE TECNICHE

DOPO IL DEPLOY
1. Attendere il completamento Cloudflare Pages.
2. Ricaricare la pagina con Ctrl+F5 una volta.
3. Entrare in un ruolo ufficio autorizzato.
4. Aprire "Configurazione azienda" dal menu.
5. Compilare l'anagrafica e/o importare il file Excel.
